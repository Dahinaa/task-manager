Task Planner es una aplicación web para organizar tareas.

Permite crear, ver, editar, eliminar y filtrar tareas por título, descripción y categoría.

Esta aplicación permite registrar tareas con título, descripción, prioridad, estado y categoría. Al igual que también permite filtrar las tareas para así poder encontrarlas más rápido. 

Para el frontend se utilizaron las tecnologías de React, TypeScript, Vite, Tailwind CSS, Axios, React Router y Heroicons. Mientras que para el backend se hizo uso de Node.js, Express, TypeScript, Sequelize, PostgreSQL, pgAdmin4, CORS y Morgan.
